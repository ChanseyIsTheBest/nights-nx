# banjo::hand::n_<id>). tools/localize_native.py puts each in front of the generated copy of its function wherever
# that copy is used (docs/enhancements.md, "Hand-written natives").
#
#   <address or generated name> [id=<namespace suffix>] [exact=<registers>]

# exact: registers the original writes that the native leaves exactly as the original does (memcpy reloads r3 with
# the value it came with). Every other register the original writes is scratch the native does not reproduce: the
# guard skips it for every hook whose copy contains the native.
